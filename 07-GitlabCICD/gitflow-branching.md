```
Branches

main → Always production-ready code.

dev → Integration branch for upcoming releases.

test or staging → branch for performing DAST, Vulnerabilities and image scanning 

feature/* → One branch per feature. Runs SAST as soon the branch is published 

hotfix/* → Immediate fixes on production. Enforces back merge to testing and dev branches 

release/* → Optional, for planned releases.
```
